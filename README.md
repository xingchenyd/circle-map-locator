# circle-map-locator

圆范围定位工具：单圆范围圈 / 两圆交点计算，支持地图点选记录与选点间直线距离测量。

**在线使用**：<https://xingchenyd.github.io/circle-map-locator/>

## 功能

- **双模式**
  - 单圆模式：在地图上显示一个范围圈（圆心 + 半径），可地图点选圆心或手动输入经纬度
  - 两圆模式：两个范围圈叠加，自动计算并标注两圆交点（通常 2 个候选点，相切时 1 个），点击即可复制交点坐标
- **快速定位城市**：先选省份再选城市，地图自动跳转到城市中心
- **选点记录**：点击地图任意位置即记录一个点（自动命名：选点1、选点2……），支持重命名、删除、定位、点击复制坐标，记录保存在浏览器 localStorage，刷新不丢失
- **直线距离**：相邻选点之间自动显示 Haversine 直线距离（km），并可在地图上显示虚线连线
- **交点精确计算**：局部等距圆柱投影下的解析解（该尺度下误差 < 1m），并实时显示圆心距

## 使用场景

已知两个位置（如两个基站、两个地标）及其覆盖半径，需要快速确定两者边缘交汇区域的位置。

## 技术说明

- 前端仅使用原生 JS + Leaflet，静态页面，无后端、无 API Key
- 底图为高德地图栅格瓦片（GCJ-02 坐标系）；工具内所有坐标均为 GCJ-02
- 城市中心坐标为近似值，仅用于快速跳转视野，不影响圆与交点的计算精度
- 交点算法：将圆心差换算为局部平面坐标（米）后解两圆方程组，再反算回经纬度

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建。
